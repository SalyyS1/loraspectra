Instant CLI Usage

curl -sL https://github.com/SalyyS1/loraspectra/releases/download/v0.1.0/loraspectra-v0.1.0-x86_64-unknown-linux-gnu.tar.gz | tar -xz
./loraspectra audit adapter_model.safetensors
./loraspectra compress adapter_model.safetensors adapter_slim.safetensors --energy 0.99
./loraspectra merge lora_a.safetensors lora_b.safetensors merged.safetensors --mode ortho-svd --rank 32
